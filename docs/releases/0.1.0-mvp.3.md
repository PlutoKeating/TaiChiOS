# TaiChiOS 0.1 MVP prerelease 3

This is the first public **bootable, installable, runnable** TaiChiOS image. It is an engineering prerelease for isolated x86_64 virtual machines, not a stable or production release.

## Verified delivery contract

The release workflow builds the binary ISO and corresponding-source ISO from this exact tag, then gates publication on:

- pinned Debian and runtime compatibility checks;
- network-isolated BIOS and UEFI Live boot;
- whole-disk installation under BIOS and UEFI;
- disk-first-boot and independent Recovery-target acceptance;
- package/source manifests, a recorded CI build toolchain, SHA-256 checksums, release metadata, and GitHub build-provenance attestation.

Download `taichios-0.1-amd64.hybrid.iso` to boot or install. Verify it from `SHA256SUMS`; `release-metadata.json` records the Debian snapshot, runtime compatibility, actual image Profile/Bundle and system-plugin digests, artifact hashes, and rollback contract. `taichios-0.1-source.iso` carries the corresponding Debian source payload, `source.contents` lists its files, and `build-environment.txt` records the CI toolchain.

## Important limitations

- The installer erases the selected disk. Use only a disposable VM disk.
- Automated acceptance covers QEMU x86_64 BIOS/UEFI; real hardware and firmware are not qualified.
- Installed factory credentials are `taichi` / `taichi` and `creator` / `creator`; there is no production credential-enrollment flow.
- The default Provider is an offline mock. Production Provider and Secret Service enrollment are not implemented.
- Secure Boot and additional firmware are disabled by the pinned image policy.
- Recovery can disable a Profile or roll back the last managed file Change Set; cross-release data migrations and full-system rollback are not provided.
- This prerelease has no production security SLA. Report vulnerabilities through GitHub Security Advisories.
